# Week01 - Student Portal

Aim: Set up Flutter and display the welcome screen of a student portal.

From the repository root: `flutter run -t Week01_setup/main.dart`

Install Flutter and Android Studio, add Flutter to PATH, then run `flutter doctor`, `flutter doctor --android-licenses`, `flutter pub get`, and `flutter devices`. Start an Android emulator or connect a phone with USB debugging. Press `r` for hot reload.
