# Week09_firebase_realtime_database

Aim: Demonstrate firebase realtime database.

From the repository root: `flutter run -t Week09_firebase_realtime_database/main.dart`

Firebase was not configured or tested against a database. Supply your own Firebase project values using `--dart-define=FIREBASE_API_KEY=...`, `FIREBASE_APP_ID`, `FIREBASE_SENDER_ID`, `FIREBASE_PROJECT_ID`, and `FIREBASE_DATABASE_URL` (each with its own `--dart-define`). Create a Realtime Database and allow this demo's read/write operations using your project's rules. No credentials are included. Without these values the screen explains that configuration is missing.
